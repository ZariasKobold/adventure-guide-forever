# Adventure Guide Forever

A World of Warcraft: Forever addon that brings back the retail **Adventure Guide**: a dungeon and raid journal with boss overviews, abilities, loot tables, and 3D models for every Forever instance.

- **Install and use:** see [AdventureGuideForever/README.md](AdventureGuideForever/README.md).
- **Develop:** see [CLAUDE.md](CLAUDE.md) for the layout and rules, and [tools/README.md](tools/README.md) for the build, tests, and data pipeline.

## Credits

Thanks to [Wowhead](https://www.wowhead.com/forever): levels, bosses, abilities, quests, loot,
NPC, spell, and model IDs come from its WoW Forever database and its dungeon and raid guides.
The guide text in this addon is our own writing, checked against those guides; Wowhead's own
text isn't copied into it. Learning mode and players' shared data fill in the rest from play.
